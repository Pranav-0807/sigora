# Sigora — India Bank Integration

Sigora uses the RBI Account Aggregator ecosystem through Setu's AA Gateway for consented Indian bank-data connectivity.

## What the launch build supports

- Connect supported Indian deposit accounts through an Account Aggregator consent flow.
- Request profile, summary and transaction data only after user consent.
- Store a connection record without storing bank passwords or UPI PINs.
- Receive Setu consent/session webhooks.
- Fetch permitted deposit-account data.
- Normalize bank transactions into Sigora's existing transaction model.
- Deduplicate imported transactions using the provider transaction ID.
- Keep original transaction currency (Indian deposit accounts are normally INR).
- Re-sync a connection from the Sigora Bank Accounts page.
- Support Setu periodic/auto-fetch when enabled for the FIU product.

Setu's current AA documentation describes consent as the core authorization contract, supports DEPOSIT + TRANSACTIONS data, and provides webhooks for consent/session state. Production access requires FIU onboarding and certification/approval; credentials cannot be generated by Sigora itself.

## Render configuration

Add these environment variables to the Render web service:

```text
SETU_AA_BASE_URL=https://fiu.setu.co
SETU_AA_AUTH_URL=https://accountservice.setu.co/v1/users/login
SETU_AA_CLIENT_ID=<production client id>
SETU_AA_CLIENT_SECRET=<production client secret>
SETU_AA_PRODUCT_INSTANCE_ID=<production product instance id>
SETU_AA_FIU_ID=<FIU id if supplied>
SETU_AA_REDIRECT_URL=https://YOUR-DOMAIN/accounts
SETU_AA_PURPOSE_CODE=101
SETU_AA_PURPOSE_TEXT=Personal financial management
SETU_AA_FETCH_TYPE=PERIODIC
SETU_AA_FREQUENCY_VALUE=1
SETU_AA_FREQUENCY_UNIT=MONTH
SETU_AA_DATA_LIFE_VALUE=1
SETU_AA_DATA_LIFE_UNIT=MONTH
SETU_AA_WEBHOOK_SECRET=<optional shared secret if configured>
```

For sandbox testing, use the sandbox values supplied by Setu for your product rather than copying production credentials.

## Setu webhook

Configure the FIU notification endpoint in Setu Bridge as:

```text
https://YOUR-DOMAIN/webhooks/setu/aa
```

If you configure a shared secret on the Setu side, set the same value as `SETU_AA_WEBHOOK_SECRET` and send it as `X-Sigora-Webhook-Secret`.

## Production requirement

A code-only ZIP cannot make real Indian bank connections live. Setu documents that production FIUs must complete the relevant onboarding/certification process and receive production credentials. Once those credentials are placed in Render, the `/accounts` flow uses the live Setu gateway.

Do not put Setu secrets in GitHub, `.env.example`, screenshots, or client-side JavaScript.
