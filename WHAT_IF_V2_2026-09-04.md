# Sigora What-If V2

## Upgrade
- Replaces the purchase-amount-first UI with a natural-language financial decision box.
- Supports English, Tamil and Hindi through Sigora's existing language system.
- AI is used only to extract intent, subject, explicit amount and timeframe.
- Product prices are never invented. If a user asks, for example, “Can I buy an iPhone?” without a price, Sigora asks only for the expected price.
- Affordability calculations remain deterministic and use recorded Sigora financial data.
- Results show current recorded buffer, post-decision buffer, share of buffer used, recent savings pace, recovery estimate and a goal in view when available.
- Removes the misleading ~0 days result when there is no positive savings pace.

## Safety model
AI interprets; Sigora calculates. The simulator is an educational planning tool based on recorded data, not a guarantee or regulated financial advice.
